# Community conduct

[简体中文](CODE_OF_CONDUCT.zh-CN.md)

Be respectful, constructive and specific. Discuss ideas and evidence, welcome contributors with different experience, and give proper attribution. Harassment, threats, discriminatory abuse, publishing personal information or credentials, spam and intentional damage are unacceptable.

The maintainer may edit or remove harmful content, lock discussions or restrict participation according to the conduct and its impact. Explain moderation decisions when practical. Use GitHub's report-content tools for abuse; report software vulnerabilities through [SECURITY.md](SECURITY.md).

This guidance applies to project issues, pull requests, discussions and other official project spaces.
