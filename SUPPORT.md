# Getting help

[简体中文](SUPPORT.zh-CN.md)

Ask usage questions and discuss ideas in [ARMHPC Discussions](https://github.com/ArmbianHPC/armbian-hpc/discussions). For defects, select the issue form in [armhpc-ota](https://github.com/ArmbianHPC/armhpc-ota/issues/new/choose) or [armbian-hpc](https://github.com/ArmbianHPC/armbian-hpc/issues/new/choose).

Include software and firmware versions, exact model/PCB revision, the operation and connection type, expected/actual behavior and redacted diagnostic output. Relevant commands include `armhpc ota status --json` and `armhpc ota doctor --json`; in Rescue use `armhpc-rescue` instead. Review output before posting.

Keep passwords, SSH/private signing keys, cluster tokens, device backups and raw identity partitions private. Hardware-watchdog or boot failures may require an on-site recovery path; record operator intervention honestly.

Read the [device guide](https://github.com/ArmbianHPC/armbian-hpc/blob/main/docs/DEVICES.md) and [known issues](https://github.com/ArmbianHPC/armbian-hpc/blob/main/docs/KNOWN-ISSUES.md). Support is provided by one volunteer maintainer as time permits.
